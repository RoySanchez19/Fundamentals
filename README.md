# Java fundamentals

Four small Java console examples from an earlier hands-on learning stage (repository created September 2023).

| File | Focus |
|---|---|
| `Variables.java` | Primitive variables and output |
| `ControlStructures.java` | Conditions, a while loop, and a for loop |
| `Functions.java` | A sum function called with two numbers |
| `ExceptionHandling.java` | Catching an intentional arithmetic exception |

## Run locally

Requires a JDK (checked with Java 21 on October 30, 2026). From the repository root:

```sh
javac -d out *.java
java -cp out Project_Fundamentals.Variables
java -cp out Project_Fundamentals.ControlStructures
java -cp out Project_Fundamentals.Functions
java -cp out Project_Fundamentals.ExceptionHandling
```

Both compilation and all four console entry points were checked. This is not a DSA solution collection, API, or database application. The source was preserved; this README was organized with AI assistance.
